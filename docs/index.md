# Documentation

A map of the pascal-mcp-sdk docs. Start with the quick start if you
want to use the library; the rest describes how it is built.

- [Quick start](quick-start.md) — install the library, write a
  server, serve it over stdio or Streamable HTTP, and register it
  with an MCP client. *For consumers.*
- [Architecture](architecture.md) — the six-unit layering, the
  sans-I/O core, and the spec-grounding notes. *For contributors.*
- [Tooling](tooling.md) — toolchain decisions and version pins. *For
  contributors.*
- [Code style](code-style.md) — formatting rules and FPC pitfalls.
  *For contributors.*
- [Deployment](deployment.md) — release and packaging. *For
  contributors.*

Contribution workflow — clone, build, test, format, CI — lives in
[CONTRIBUTING.md](../CONTRIBUTING.md).
